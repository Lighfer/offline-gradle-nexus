额外源仓库（仅 inspect/resolve 阶段叠加） 用于工程已切到只读目标 Nexus、仍需从原始源拉依赖的场景

这里填写的仓库会在 Gradle init script 里前置到工程现有仓库前面，但不会清空工程已声明的仓库； 仅对本工具自己的 inspect/resolve 任务生效，不会改写用户工程的 settings.gradle / build.gradle。 典型用法：把仓库切到目标空 Nexus 后，依然能从原 Nexus group（如 maven-public）拉到 SNAPSHOT 与 plugin。

验证 fatjar 一致性

把工具下载下来的依赖（<outputDir>/repo/*.jar）与 build 出来的 Spring Boot fatjar 内部 BOOT-INF/lib/*.jar 做精确比对。匹配优先级：(group, artifact, version, classifier) > fileName。

填写 fatjar 路径后点击「开始验证」。

上传到 Nexus 3

扫描本地导出目录后选择目标仓库，按 Maven Layout 通过 PUT 上传。默认 dry-run，确认无误后再实际上传。

扫描或上传后会展示完整列表。
